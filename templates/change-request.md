# 返工修改单

一轮只改一类：先版式 → 再配色 → 再细节，不要混在一轮。一轮 ≤5 条，超过拆两轮。锁定项不许动。基于哪个版本要写明。列「不要改」清单。

别说：高级、大气、好看、现代一点。改说：留白加大到 24px、标题加大一号、主色只用在按钮上、参考这张图的排版密度。说不清时：截图圈出来 + 「这里太挤/太空/看不清」。

复制填写：

```
基于版本：<v__，文件名或截图>
本轮只改这一类：<版式 / 配色 / 细节>
只改这几条，其他全部保持不变，锁定项不许动：
1. <位置> 把 <原样> 改成 <目标>，原因：<原因>
2. <位置> 把 <原样> 改成 <目标>，原因：<原因>
3. <继续，最多 5 条>

不要改：<明确列出满意、禁止动的部分>
改完给我：新截图 + 改动清单（逐条对应上面编号）+ 没改什么
```

## Agent 回执

对不上不算交付。回执用这个格式：

```
基于版本：<与修改单相同>
新截图：<桌面 + 手机（默认 390x844）>
页面文字重读：<已核对的结果>
逐条对应：
1. <对应修改单第 1 条>
没改什么：<明确列出，含未动的锁定项>
另存为：<name-vN，不覆盖上一版>
```

版本另存、不覆盖。工作流：`name-v1 / v2 / v3`，定版标母版。返工模板：`name-v1.html`, `name-v2.html`...，定版标 `-final` / 母版。

## 微调快车道

三条全部满足才用这条，免走上面的整轮修改单：① 不超过 3 处 ② 只动字号档/间距/字重/颜色中的一类数值 ③ 不动版式结构、不解锁方向。

原文示例：

```
微调，基于 v3：正文 body 升一档（14→16）；区块标题不突出，升一档（20→24）；其他不动。改完只给我手机版前后对比截图。
```

照这个句式填：

```
微调，基于 <版本>：<不超过 3 处，且只动字号档、间距、字重、颜色中的一类>；其他不动。改完只给我手机版前后对比截图。
```

快车道回执：前后对比截图（同尺寸同位置）+ 改了哪几个 token/组件 + 溢出检查结果。改的若是 token，记入 `CHANGELOG-UI.md`。
