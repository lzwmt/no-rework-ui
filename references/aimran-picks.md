# AIMRAN 精选索引（动效货架）

关 4 加动效时先查这里取现成件，别从零手写。Emil / animate 系列管「动效怎么做才对」（曲线、时长、该不该动），本索引管「现成件在哪」，两层互补。

来源：AIMRAN Library（https://library.aimran.es ，作者 Aimran Oukham），814 个免费动效组件、免注册。本索引于 2026-11-10 从其全量目录逐类筛出 24 件，只收与常见产品场景对口的。适用路线：手写路线（前台页/落地页/H5）。Astryx 路线用其组件自带动效、uni-app 路线以其组件库为准，均不走本索引。

## 取件方式

- 全代码：`https://library.aimran.es/md/<组件id>.md`（HTML / CSS / JS / React 版都在同一文件里）
- 在线调参页：`https://library.aimran.es/blocks/<组件id>`（可在线改颜色/尺寸/速度/文案再取码）
- 全量目录：`https://library.aimran.es/llms-full.txt`（索引里没有的件按类现查；分类页 `https://library.aimran.es/components/<类名>`）

## 取件纪律

1. 只取 HTML + CSS 类（`uv-`、`css-` 前缀基本都是）；标 React + Motion 的件不进手写/Vue 项目，React 项目也先看有没有 CSS 版。
2. 进项目必改 tokens：颜色、字号、圆角换成本项目 `design-tokens.md` 的变量，不许带原码默认配色进站。
3. 手机优先：hover 独占触发的件必须改自动触发或点击触发（先例：主按钮扫光改成约 3.8 秒周期自动扫光）；触屏触发不稳的件（如 uv-card-flip）背面不放关键信息。
4. 每页克制：一页只许一个主特效位（扫光按钮、旋转徽章这一量级二选一），其余只许反馈类小动效（点击波纹、toast、骨架屏）。全页都闪 = 老虎机。
5. 无障碍不许删：多数件自带 `prefers-reduced-motion` 段，取件时保留；删了要按 Emil 口径补回。加载类保留 `role="status"` / `aria-live`。
6. 许可：官网称免费、无需注册，但首页未明示商用授权条款；自有产品先行使用，客户商用项目交付前再向作者确认。

## 没入选的类别（需要时现查全量目录）

- 404 整页（45 件）：报错页整页模板，项目真要做 404 页时按行业现查。
- 背景 patterns（58 件）：全屏动效背景与 Emil 的克制口径冲突，默认不用；活动页要氛围时现查并单独报批。
- Liquid Glass（43 件）：多为 React + Motion，且是苹果风整套界面件，与手写路线 tokens 体系不合，暂不收。
- 导航 navigation（42 件）：多为 React + Motion，且各技术栈自带导航模式，不收。
- 提示气泡 tooltips（44 件）：桌面 hover 件，手机无用，不收。
- 筛选 filters、复选 checkboxes、其余 radios：场景窄或猎奇件多（如缝纫机加载、捕蝇草开关），真遇到对应场景再现查。
