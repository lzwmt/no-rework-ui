# 备选路：先生图、后还原

v1.2 借自 Oil UI 的 image-ideation。本节按已经并入关 2 的文字执行。

什么时候走：直出小样排版平庸/方向定不下、或用户想先看图定方向时，先用生图定构图与配色，再照图写代码。不是默认路，关 2 主线仍是技能直出。

工作区/后台页若走这条路，还原尺度见 `admin-workspace.md`。

## 生图

生图走执行环境自带的生图能力。

提示词短（约 45–65 词、2–3 句），只定结构关系、比例留白与色彩角色，把构图权留给生图模型，不写逐行线框说明书。忌 oversized/giant/thick 这类词（会连带放大侧栏与按钮）。

## 色彩范围法

新建项目按约 85:10:5——八成半无彩骨架（高明度低彩度底色 + 哑光黑/炭灰控件 + 中性灰辅助）、约一成低明度重色锚点、半成单点高亮。存量项目直接继承既有底色与品牌色，不另起一套。

## 还原纪律

设计图只是骨架、配色与视觉重心的参考，不是像素描红的图纸。

- 只采样色板与横向分栏比例，绝不照搬生图被压缩的纵向间距（长图尤其明显）。
- 落地页各模块上下间距按真实网页拉开（首屏给足视口高度、模块 padding-block 约 88–136px）。
- 字号一律回到关 3 字号阶梯（`type-and-tokens.md`），不抄图里的畸形小字。
- 严禁用整张位图当页面背景、用绝对定位锁像素复刻。

还原做完，仍按 `sampling-and-vendors.md` 的交付格式交 HTML + 截图，并过数据自洽。
