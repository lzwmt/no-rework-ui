# 字号、字体与锁定项

关 3 的锁定流程和 tokens 双轨制见 `gates.md` 关 3。本文件是字号阶梯、三类改法、中文字体栈、嵌套圆角、克制三条，以及锁定表填写项的出处。AI 味自查归关 6，见 `review-and-rework.md`。

## 锁定项

把选中方向抽成锁定表，必锁：配色 hex、字体、字号阶梯、圆角、间距（8 的倍数）、按钮/卡片/导航样式。

落成 `design-tokens.md`，并写进代码里的 CSS 变量 / tailwind theme，全项目只认这一份。

锁定源以复核者从样稿代码逐值提取的版本为准。出样者自带的 tokens 清单只作意图参考。两者差异逐条裁定，决定补充进锁定版的走 `CHANGELOG-UI.md` 留痕。

锁定后改 tokens = 全站变更，必须用户明确说「解锁改 X」，并记一行变更记录。锁定后用这句约束后续修改：`以上为锁定项，除非我明确说解锁，否则任何修改都不得变更。`

返工模板的锁定表（选定后把定版值填进表；改一次记一次）：

| 项 | 定版值 | 备注 |
|---|---|---|
| 配色 | 背景 # / 主色 # / 点缀 # / 文字 # | 例：个人主页 2号墨绿米白 #E8E3D5 / #355E3B / #E9B44C |
| 字体 | 标题： / 正文： | 只用 1-2 种 |
| 圆角 | 小 8 / 中 16 / 大 24 | 全站统一 |
| 间距 | 8 的倍数：8/16/24/32 | |
| 风格词 | 如：粘土风、干净、克制 | 3 个词封顶 |
| 组件 | 按钮、卡片、导航长什么样 | 出图后截图存档 |

配色格里的 #E8E3D5 / #355E3B / #E9B44C 是个人主页 2 号的例子。圆角「小 8 / 中 16 / 大 24」、间距「8/16/24/32」是返工模板给出的刻度。已有选中样稿时，表里填复核者从样稿逐值提取的结果；出样者自带清单只作对照，差异按 `gates.md` 关 3 的双轨制裁定。

## 字号阶梯

先定一套字号阶梯，全站只用这几档，不许随手发明 15px、19px、27px：

| 档位 | 建议值（桌面 / 手机可同值，靠档位区分） | 用途 |
|---|---|---|
| caption | 12px | 脚注、时间、辅助说明 |
| body-sm | 14px | 次要正文、列表说明 |
| body | 16px | 正文默认 |
| title-sm | 20px | 卡片标题、小节标题 |
| title | 24px | 页面区块标题 |
| hero | 32-40px | 首屏大标题，只出现 1 次 |

行高跟字号绑定：正文 1.5-1.6、标题 1.2-1.3；字重只用 400/600/700 三档。

### 展示档（可选，方向里有超大展示数字时才开）

| 档位 | 建议值 | 用途 |
|---|---|---|
| display | 64–96px | 统计大数字（达标天数、时长） |
| monument | 160–360px | 纪念碑数字，全图只出现 1 次 |

规矩：
- 展示档只用于数字和极短的词，行高为 1，字距 -0.03 到 -0.05em。
- monument 必须在格子内完整露出，按 `composition.md` 第一节第 4 条，字不出血。
- 真页面在手机 390 宽下，monument 按格宽缩放，或降为 display。
- 展示档的值写进锁定表；4b 用的值必须与锁定表一致。

## 字号三类改法

改字号时先分清是哪一种，不要一律改单个元素：

1. **全局问题**——「正文普遍看不清/太小」：这是改 tokens。例：body 14→16，全站一处改、处处生效。走解锁流程，在 `CHANGELOG-UI.md` 记一行：日期 + 改哪档 + 旧值→新值 + 原因。
2. **层级问题**——「这个标题不突出」：多半不是给它发明新字号，而是让它在阶梯上升一档（20→24），或给正文降一档拉开差距。优先升/降档，不新造数值。
3. **单点例外**——「就价格数字要特别大」：允许单点例外，但要在代码里标明是例外组件（如 Price），不扩散到其他地方；例外超过 3 处，说明阶梯定错了，回头改阶梯。

用户提意见时不用会说 px，执行本技能的 agent 翻译成档位：

- 「正文太小，看得累」→ 查 body 档 + 行高 + 对比度（很多时候是颜色太浅，不是字小）
- 「标题和正文分不开」→ 标题升一档或加粗一档，二选一，不要又大又粗又换色一起上
- 「这行字太挤」→ 先动行高/间距，不先动字号

改完必验：字号变大最容易撑爆——手机 390 宽截图复查不溢出、不截断、按钮文字不换行挤压，不过不算改完。

## 中文字体栈

西文字体在前、中文字体在后、sans-serif 兜底。每个项目在 tokens 里把字体栈写死：

```css
font-family: <西文字体>, -apple-system, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif;
```

来源：@ricouii。这一条补上了落地页技能只有拉丁字体的缺口。

## 嵌套圆角

内圆角 = 外圆角 − 间距（gap <32px 时适用，结果 ≤2 则不强改）。想要 iOS 那种连续圆角用 superellipse。来源：@Kubai087。定版写明与落地页技能 B3 同一公式，互为印证。定版没有展开 B3，执行只认这条公式。

## 克制三条

- 字号档位宁少勿多（帖中 @ZaynHao 主张 ≤4 种，与本工作流阶梯制一致，执行以阶梯为准）。
- 细边框可用 0.5px。
- 颜色克制——黑白灰打底、颜色留给内容本身（@ianneo_ai）。
