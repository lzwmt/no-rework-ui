# 工作区 / 后台页临时口径

中后台口径借自 Oil UI 公开方法中的工作区布局一段。成套中后台轨道未立，此为临时口径，等真实项目再定。

做仪表盘、数据表、表单这类工作区页面时，先按这段口径兜底：

- 首屏就是第一排内容/工作区本身，不放首屏口号、不放解释页面用途的段落。面包屑、标题、实时状态与全局筛选合并为一排紧凑顶栏（约 56–64px），第一排内容完整出现在首屏。
- 多模块后台用紧凑三行布局：首行约 4 张指标卡（可内嵌进度环）、中行主态势图配动态流、末行主数据表配排行。在 1440×900 视口内同时露出核心模块与主表前几行。
- 完整详情与日志在选中对象后滑出或展开，不用多层小卡片和满屏彩色标签把桌面塞满。
- 若走先生图备选路（`image-first.md`）：还原时去掉生图外围的窗口外框与画布留边、界面铺满视口。主画布与卡片间距 20–28px、卡片内边距 22–28px、表格与列表单行高度 44–56px（真实可点击尺度）。

字号仍回 `type-and-tokens.md` 的阶梯。其余关 4 规则（标杆页、组件化、tokens 一致、动效后加）见 `gates.md` 关 4。
