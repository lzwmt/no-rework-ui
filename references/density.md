# 密度纪律（配额、格随内容、读数验收）

本文件管「每格装多少东西、拿什么证明装够了」。构图原则在 `composition.md`，本文件是它的机械执行层：**主观自查不替代读数**。出处：2026-11-02 实测——同一技能在弱执行者手里自查「构图八问全过」，成品却多格大面积空白；问题不在规则缺失，在验收靠自觉。本文件的条都是为了让不合格自己暴露出来。

## 一、逐格内容配额（关 1 写死，关 4 照做）

- brief 里每格一张配额表：格名、信息元素清单（逐项列）、元素数下限。例如：逐字稿格 ≥8 行（每行含时间戳+说话人+一句真内容）；纪要格 ≥4 条要点；柱状图格 =12 根柱 + 均值线 + 12 个月份标签。
- 元素指**有信息量的单位**：一行真文字、一根柱、一个数据点、一枚标签。装饰线、空白分隔、纯色块不算元素。
- 配额由内容决定，不许先定格数再凑内容。内容撑不起一格的，不配独立成格（见第二节）。
- 关 2 小样可以低于配额（只验方向），关 4 成品必须满配额。

## 二、格随内容定（关 4 版式）

- 版式顺序：先列全部格的内容清单 → 按内容量定格子大小与数量 → 最后排网格。禁止先画等大网格再往里填。
- 某格两轮修改仍达不到配额或密度读数：该格必须缩小、并入邻格或取消，不许保留空格充数。
- 主角格可以大，但大要用内容撑：主角数字 + 至少两个副信息（如对比值、口径注、迷你图）。

## 三、密度读数（关 5 必跑，脚本在 ../scripts/density_check.py）

对最终成品 PNG 逐格量两个读数：

- **ink**：内容像素占格面积比例（格内主导色之外的像素）。
- **bbox_fill**：内容外接矩形占格面积比例（内容摊得开不开）。

默认门槛：`bbox_fill ≥ 0.35` 且 `ink ≥ 0.05`。纯图形格（波形、热力图）可在 layout 里单独调低 ink，但必须在 brief 里预先声明，不许事后改门槛迁就成品。

执行步骤：

1. 按成品的实际网格写 `density-layout.json`（每格 name + 相对坐标 x/y/w/h + 可选 min_ink/min_bbox_fill）。HTML 实现时每格加 `data-cell="<格名>"`，坐标从渲染布局量，不许凭目测估。
2. 跑 `python3 scripts/density_check.py <成品.png> density-layout.json density.json`。
3. 任一格 FAIL = 本轮不合格，第一条修改单就是它；改完重跑脚本，直到全 PASS。
4. `density.json` 原文必须进 `reviews/review-vN.md` 和 DONE 清单。只写「密度已查/构图问答全过」而拿不出 density.json 的，视为未查。

若执行环境能跑页面脚本（Playwright 等），可用同一口径的 DOM 版替代：以元素包围盒采样算 ink 与 bbox_fill，产出同结构 density.json 即可，门槛不变。

## 四、自查证据规则（关 5）

- 构图问答（composition.md 第六节）每题的回答必须附证据：density.json 的对应读数、碰撞检测的计数、或截图上的区域坐标。只写「是 / 通过 / 已检查」的答案无效，按未查处理。
- 自报的数字（尺寸、格数、元素数）必须来自文件实测（读图尺寸、数 DOM、跑脚本），不许凭记忆写。
- 自查发现 FAIL 时必须留痕：reviews 里记 FAIL 项 + 修改动作 + 复验读数。不许只报最终全 PASS 的版本。
